# AKRON Logistics — neveřejný koncept

Čtyřstránkový koncept v Next.js 16 a TypeScriptu.

## Spuštění

```bash
pnpm install
pnpm dev
```

## Před publikováním

- doplnit skutečný telefon a e-mail a následně připojit odesílání poptávky;
- dodat logo a fotografie firmy/vozidel;
- přihlásit se ke GitHubu a Vercelu a založit soukromý projekt;
- po nasazení odstranit `noindex, nofollow` až při schváleném zveřejnění.
